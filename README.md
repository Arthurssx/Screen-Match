# Screen Match

Projeto que estou desenvolvendo durante meus estudos de Java na Alura.

Uso filmes e séries para praticar POO, avaliações, listas e ordenação.
Vou atualizando o código conforme avanço nas aulas.

## Como executar

Estou usando o IntelliJ e o JDK 25. Para testar, abra o projeto e execute:

- `Principal`, com os exemplos de filmes, séries e avaliações.
- `PrincipalComListas`, com os exemplos de listas e ordenação.

As instruções dos testes estão na pasta [tests](tests/README.md).
